# دموی شیفت کلینیک (نسخه آفلاین، بدون Claude و بدون VPN)

اپ وب نصب‌شدنی (PWA) برای نشان دادن برنامه‌ریزی شیفت کلینیک به مدیر مجموعه، با ثبت خودکار بازخورد برای توسعه‌دهنده.

- همه منطق برنامه (شیفت‌چینی، قوانین، درخواست نبودن، آنکال‌ها، ترجیح دکتر، PDF و Excel) داخل مرورگر اجرا می‌شود.
- فهم متن فارسی با موتور قاعده‌محور `public/nlu.js` انجام می‌شود؛ هیچ سرویس خارجی یا مدل زبانی لازم نیست.
- فونت، کتابخانه‌ها و آیکون‌ها داخل پروژه‌اند؛ هیچ درخواستی به گوگل یا CDN خارجی نمی‌رود.
- سرور `server.js` بدون هیچ وابستگی (فقط Node 18 به بالا) است و فقط دو کار می‌کند: سرو کردن اپ، و دریافت و نمایش بازخوردها.

## ساختار

```
server.js              سرور: فایل‌های اپ + /api/feedback + داشبورد /admin
public/index.html      پوسته اپ
public/app.js          منطق اصلی برنامه (شیفت‌چینی، قوانین، درخواست‌ها، …)
public/nlu.js          موتور فهم متن فارسی (قاعده‌محور)
public/platform.js     ذخیره محلی، داده نمونه، بازخورد، نصب و به‌روزرسانی
public/sw.js           service worker (کش آفلاین + اعلام نسخه جدید)
public/manifest.webmanifest, icons/   تنظیمات حالت اپ و آیکون‌ها
public/fonts, vendor/  فونت وزیرمتن، html2pdf و SheetJS (همراه با مجوزهایشان)
tests/nlu.test.js      تست جمله‌های فارسی
scripts/bump.js        بالا بردن شماره نسخه + متن «چه چیزهایی عوض شد»
liara.json             تنظیمات استقرار روی لیارا
```

## اجرا روی کامپیوتر خودت

```bash
npm test                      # تست موتور فهم متن
ADMIN_PASSWORD=یک-رمز-قوی npm start
```

بعد `http://localhost:3000` را باز کن. داشبورد: `http://localhost:3000/admin` (نام کاربری `dev`).

نصب به‌صورت اپ فقط روی HTTPS (یا localhost) ممکن است. برای تست روی گوشی خودت، یا روی هاست منتشر کن، یا در کروم کامپیوتر با DevTools حالت موبایل را امتحان کن.

## انتشار روی هاست ایرانی (مثال: لیارا)

این مراحل کلی است؛ جزئیات پنل ممکن است عوض شده باشد، پس با مستندات خود سرویس چک کن.

1. یک نفر داخل ایران حساب بسازد و اعتبار شارژ کند.
2. در پنل یک برنامه **Node.js** با نام `clinic-shift-demo` بسازد (یا نام دیگر، و همان را در `liara.json` بنویسد).
3. یک **دیسک** با نام `feedback-data` بسازد (کوچک‌ترین اندازه کافی است) تا بازخوردها بعد از هر استقرار پاک نشوند.
4. در تنظیمات برنامه متغیر محیطی `ADMIN_PASSWORD` را با یک رمز قوی بگذارد.
5. استقرار:
   ```bash
   npm i -g @liara/cli
   liara login
   liara deploy
   ```
6. آدرس برنامه (مثلاً `https://clinic-shift-demo.liara.run`) را برای مدیر بفرست.

روی هر سرور مجازی دیگر هم کافی است `node server.js` را اجرا کنی و جلویش یک Nginx با گواهی HTTPS بگذاری. متغیرها: `PORT`، `DATA_DIR`، `ADMIN_PASSWORD`، `ADMIN_USER`.

**یک نکته:** بعضی سرویس‌های ایرانی ترافیک خارج از ایران را محدود می‌کنند. اگر داشبورد از اسپانیا باز نشد، مدیر می‌تواند از داخل اپ «ارسال همه نظرها با پیام‌رسان» را بزند.

## نصب روی گوشی مدیر

- **اندروید:** لینک را در Chrome باز کند؛ بنر «نصب» بالای صفحه می‌آید، یا از منوی سه‌نقطه «Install app».
- **آیفون:** لینک را فقط با **Safari** باز کند ← دکمه Share ← «Add to Home Screen» ← Add.

اپ بعد از نصب بدون نوار آدرس و تمام‌صفحه باز می‌شود و بدون اینترنت هم کار می‌کند (بازخوردها در صف می‌مانند و بعداً ارسال می‌شوند).

## بازخورد و بهبود

اپ این‌ها را خودکار به `/api/feedback` می‌فرستد (فقط متن و زمینه؛ نه IP):

| نوع | یعنی |
|---|---|
| `feedback` | نظری که کاربر با دکمه «نظر» نوشته، همراه نقش، صفحه و ۱۰ کار آخرش |
| `nlu_miss` | جمله‌ای که موتور کامل نفهمیده، با بخش نفهمیده |
| `nlu_correction` | کاربر برداشت موتور را در جدول تأیید اصلاح کرده |
| `nlu_ok` | جمله‌هایی که درست فهمیده شده‌اند (برای درصد موفقیت) |
| `error` | خطای جاوااسکریپت |

در `/admin` این‌ها را با فیلتر می‌بینی و JSON یا CSV می‌گیری.

**چرخه بهبود موتور فهم متن:**
1. در داشبورد تب «نفهمیده‌ها» و «اصلاح‌ها» را ببین.
2. عبارت جدید را به دیکشنری‌های بالای `public/nlu.js` اضافه کن (مثلاً `"شیفت دوم"` در فهرست عصر).
3. همان جمله را به `tests/nlu.test.js` اضافه کن و `npm test` بزن.
4. نسخه را بالا ببر و منتشر کن:
   ```bash
   node scripts/bump.js 0.2.0 "«دوشنبه‌ها» حالا درست فهمیده می‌شود" "دکمه جدید برای …"
   liara deploy
   ```
   اپ مدیر خودش «نسخه جدید آماده است» را نشان می‌دهد و بعد از به‌روزرسانی، فهرست تغییرات را می‌بیند.

## محدودیت‌های این دمو

- داده‌ها فقط روی همان گوشی است؛ کارکنان مختلف روی گوشی‌های جدا هم‌زمان نمی‌بینند. منوی «من:» برای امتحان همه نقش‌ها با یک گوشی است.
- ورود با رمز یا پیامک ندارد.
- پیام‌ها فقط داخل اپ نمایش داده می‌شوند؛ پیامک و نوتیفیکیشن در نسخه واقعی اضافه می‌شود.
- «شروع دوباره دمو» در صفحه راهنما همه تغییرات را پاک می‌کند و داده نمونه را برمی‌گرداند.
